# Метрики опыта со сбоем

Источник: CloudWatch `AWS/SQS`, `GetMetricStatistics`, минутные значения
`Maximum`, UTC, 26 ноября 2026. CSV содержит фактическую выборку двух метрик:
`ApproximateNumberOfMessagesNotVisible` очереди `timecapsule-dev-mail` и
`ApproximateNumberOfMessagesVisible` очереди `timecapsule-dev-mail-dlq`.
Метрики приблизительные и могут приходить с задержкой.
