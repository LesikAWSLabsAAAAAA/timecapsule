# Запрос Seal capsule

Фактические данные записаны через сетевой захват браузера (Chrome DevTools
Protocol): один POST до изменения и один после него, без тел запросов и
cookie. CSV содержит время начала, путь, HTTP-статус и `durationMs` захвата.
Это не скриншот вкладки Network и не статистическое исследование: здесь всего
по одному запросу. Успешный POST перенаправлял браузер на страницу капсулы.
