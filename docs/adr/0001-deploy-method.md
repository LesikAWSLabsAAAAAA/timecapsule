# ADR-0001. <Название решения>

## Статус: принято
## Дата: 09.10.2026
## Контекст

Для приложени КапсульВремени необходим вычислительный экземпляр Amazon EC2 с поддержкой веб сервера, интерпретатора языка PHP и базой данных PostgreSQL. Всё было выполнено согласно курсу господина Нартя.


## Решение

Используем Amazon Linux 2023, nginx, php-fpm, postgresql, ec2.


## Рассмотренные альтернативы

Использование декларативной операционной системы GNU Guix, от которой, однако, пришлось отказаться ввиду отсутсвия образа AMI и крупной лени.


## Последствия

Всё работает очень круто, но не декларативно и не удобно мне.
